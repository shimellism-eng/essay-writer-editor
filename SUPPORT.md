# Support

This public beta is community-supported.

## Start with these checks

If the skill is not working:

1. Confirm the folder ends with `essay-writer/SKILL.md`, not `essay-writer/essay-writer/SKILL.md`.
2. Start a new AI task after installing or updating the skill.
3. Begin the request with `Use $essay-writer`.
4. State the mode you want: Plan, Draft, Edit, Review, Research or Detect.
5. For a draft, include the prompt, word limit, audience, source restrictions and rubric when available.
6. For an edit, say how much change you want and what must be preserved.
7. For Detect mode, provide enough text; fewer than 200 words normally receives an insufficient-text result.

The [README](README.md) contains full installation and verification instructions.

## Where to ask

- Use a **bug report** for reproducible failures.
- Use a **feature request** for a new essay type, workflow or improvement.
- Use an **AI-writing analysis report** when Detect mode appears too confident, misses important counterevidence or treats human writing unfairly.
- Use a repository discussion for general questions if discussions are enabled.
- Follow [SECURITY.md](SECURITY.md) for security or privacy issues.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md) for a conduct concern.

Before posting publicly, remove names, student numbers, contact details, private links, unpublished application material and confidential sources. A minimal synthetic example is usually enough.

## Helpful details

Include:

- what you asked;
- what happened;
- what you expected;
- the agent and version, if known;
- how you installed the skill;
- whether the problem happens in a new task;
- a short example you are allowed to share.

Screenshots should not reveal private essay text, account details or hidden instructions.

## Limits of support

The maintainers cannot:

- decide whether using AI is allowed for a particular assignment;
- guarantee a grade, plagiarism result or detection result;
- verify authorship from text alone;
- recover deleted drafts;
- provide account support for an AI platform;
- promise compatibility with every agent version.

For assignment rules, ask the relevant teacher, institution, editor or workplace. For account, billing or service problems, contact the provider of the AI tool you are using.
